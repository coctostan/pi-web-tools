Search the web to discover relevant pages.

**Use when:**
- you need to find sources, documentation, announcements, or external references
- you do not yet know the exact URL to fetch

**Prefer over:**
- `code_search` for general web/document discovery
- `fetch_content` only when you already have a specific URL

**Tips:**
- use `includeDomains` and `excludeDomains` to control source quality
- use `detail: "highlights"` when short summaries are insufficient
- after finding a promising result, use `fetch_content` or `get_search_content` for deeper reading
