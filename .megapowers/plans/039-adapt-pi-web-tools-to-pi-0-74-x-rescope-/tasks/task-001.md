**Justification:** Tooling/install step. Subsequent tasks need `@earendil-works/pi-coding-agent`, `@earendil-works/pi-tui`, and `@earendil-works/pi-ai` resolvable from `node_modules/` so that test files importing them compile and resolve. We add them as **devDependencies** (and ALSO flip `peerDependencies` later in Task 5 — kept separate to isolate manifest changes). Legacy `@mariozechner/*` install entries stay temporarily so the test suite remains green between tasks.

**Files:**
- Modify: `package.json` (add `devDependencies` for new peers, do NOT touch `peerDependencies` yet)
- Modify: `package-lock.json` (regenerated by npm)

**Step 1 — Make the change**

Run from repo root:

```bash
npm install --save-dev \
  @earendil-works/pi-coding-agent@^0.74.0 \
  @earendil-works/pi-tui@^0.74.0 \
  @earendil-works/pi-ai@^0.74.0
```

After install, verify `package.json` now contains in `devDependencies`:

```json
"devDependencies": {
  "@earendil-works/pi-ai": "^0.74.0",
  "@earendil-works/pi-coding-agent": "^0.74.0",
  "@earendil-works/pi-tui": "^0.74.0",
  "typescript": "^5.7.0",
  "vitest": "^3.0.0"
}
```

Do not modify `peerDependencies` in this task. Do not change `version`. Do not remove legacy `@mariozechner/*` entries that npm may auto-deduplicate — only the new packages are added.

**Step 2 — Verify**

Run:

```bash
ls -d node_modules/@earendil-works/pi-coding-agent \
       node_modules/@earendil-works/pi-tui \
       node_modules/@earendil-works/pi-ai
node -e 'console.log(require("@earendil-works/pi-coding-agent/package.json").version)'
node -e 'console.log(require("@earendil-works/pi-tui/package.json").version)'
node -e 'console.log(require("@earendil-works/pi-ai/package.json").version)'
npm test 2>&1 | tail -5
```

Expected:
- All three directories exist
- Versions print `0.74.0` (or newer 0.74.x)
- `Tests  258 passed (258)` — full suite still green, source files untouched
