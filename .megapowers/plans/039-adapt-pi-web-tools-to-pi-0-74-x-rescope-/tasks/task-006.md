Addresses **Fixed When #3** (issue #028) manifest half. Flip `peerDependencies` to the new scope at `^0.74.0`, leave `typebox` peer correct, bump `version` to `4.0.0`.

Diagnose-phase decision: pi 0.74's `pi-ai` depends on the bare `typebox` package (`typebox: ^1.1.24`), not `@sinclair/typebox`. `index.ts:3` imports `{ Type } from "@sinclair/typebox"`. **Action:** flip to bare `typebox` in source and peer, since pi-ai itself re-exports `Type` from `typebox`. Verify by reading `node_modules/typebox/package.json` after Task 1 install (npm should have brought it in as a transitive dep of `@earendil-works/pi-ai`).

**Files:**
- Modify: `package.json`
- Modify: `package-lock.json` (regenerated by `npm install`)
- Modify: `index.ts` (line 3 — `@sinclair/typebox` → `typebox`)

**Step 1 — Write the failing test**

Extend `scope-rescope.test.ts` (created in Task 5). Append the following inside the existing `describe("npm scope rescope", …)` block:

```ts
  it("package.json peerDependencies are on @earendil-works/* scope at ^0.74", () => {
    const pkg = JSON.parse(readFileSync("package.json", "utf8"));
    expect(pkg.peerDependencies).toBeDefined();
    expect(Object.keys(pkg.peerDependencies).sort()).toEqual([
      "@earendil-works/pi-coding-agent",
      "@earendil-works/pi-tui",
      "typebox",
    ]);
    expect(pkg.peerDependencies["@earendil-works/pi-coding-agent"]).toBe("^0.74.0");
    expect(pkg.peerDependencies["@earendil-works/pi-tui"]).toBe("^0.74.0");
    expect(pkg.peerDependencies["@mariozechner/pi-coding-agent"]).toBeUndefined();
    expect(pkg.peerDependencies["@mariozechner/pi-tui"]).toBeUndefined();
    expect(pkg.peerDependencies["@sinclair/typebox"]).toBeUndefined();
  });

  it("package.json version bumped to 4.0.0", () => {
    const pkg = JSON.parse(readFileSync("package.json", "utf8"));
    expect(pkg.version).toBe("4.0.0");
  });
```

**Step 2 — Run test, verify it fails**

Run: `npx vitest run scope-rescope.test.ts`

Expected: FAIL — `AssertionError: expected [ '@mariozechner/pi-coding-agent', '@mariozechner/pi-tui', '@sinclair/typebox' ] to deeply equal [ '@earendil-works/pi-coding-agent', '@earendil-works/pi-tui', 'typebox' ]`.

**Step 3 — Write minimal implementation**

In `package.json`:

- Bump `"version": "3.0.0"` → `"version": "4.0.0"`
- Replace the `peerDependencies` block with:

```json
"peerDependencies": {
  "@earendil-works/pi-coding-agent": "^0.74.0",
  "@earendil-works/pi-tui": "^0.74.0",
  "typebox": "^1.1.0"
}
```

In `index.ts` line 3, replace:

```ts
import { Type } from "@sinclair/typebox";
```

with:

```ts
import { Type } from "typebox";
```

Then run:

```bash
npm install
```

to regenerate `package-lock.json` and pull `typebox` if it isn't already transitive. Verify with:

```bash
node -e 'console.log(require("typebox/package.json").version)'
```

(should print 1.1.x).
